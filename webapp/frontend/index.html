It will not invent the numbers on your bill.

VeriScript turns photos, scans and PDFs into cleaned pages, searchable PDFs, transcripts and Markdown — and puts every uncertain number in a review queue instead of guessing. Devanagari (Nepali/Hindi) first; it runs on your machine with no cloud calls, no telemetry and no account.

Try the studio · Nepali OCR · Source code (MIT)

What you get

  • Searchable PDF — the cleaned page with an invisible Unicode text layer (Devanagari included)
  • A numbered review overlay: accepted, uncertain, and digit conflicts with the alternative reading kept
  • Transcript (.txt), Markdown (.md) and OCR JSON (tokens, risk flags, review queue)

Measured, not asserted

Modern Devanagari government PDFs: CER 0.135 [0.097–0.186]. Letterpress books: CER 0.434 [0.387–0.481]. Review-queue digit recall@10: 0.88 letterpress / 0.38 PDFs. Read the benchmark.
