Nepali OCR · Devanagari first · offline by design

Nepali OCR that does not guess your numbers.

VeriScript reads printed Devanagari from photos, scans and PDFs and turns it into a searchable PDF, plain text and Markdown. When a digit is uncertain it is flagged with its alternative reading in a numbered review queue — instead of being silently guessed. It runs on your machine; no account, no cloud calls.

What do you get from a page?

  • Searchable PDF — the cleaned page plus an invisible Unicode text layer, Devanagari included (bundled Mukta font). Selectable and copyable.
  • Review overlay — the page with numbered boxes: accepted, uncertain, and digit conflicts with the alternative reading kept next to the box.
  • Transcript — reading-order plain text, with layout decided from evidence (columns, tables, rotation), not defaults.
  • Markdown — the transcript plus the review queue as a table, ready for notes or a CMS.
  • OCR JSON — every token, risk flag, and the orientation/reading-order evidence behind the decisions.

Why a review queue, and not just OCR text?

A confidence number is not a review. On a bill, a land deed (लालपुर्जा) or a court register, one wrong digit changes the amount or the case number — and mainstream engines report their errors only as scores, never as “check this token”.

VeriScript re-reads digits, ranks them by risk, runs a calibration model, and keeps the conflicting alternative reading whenever two passes disagree. Impossible sequences and script mismatches are flagged the same way. The user check is therefore a short, ordered list — not a re-proofread of the whole page.

Measured on frozen sets: the queue surfaces 88% of wrong digits (letterpress) and 38% (modern government PDFs) within its first ten rows — up from 73%/15% before the re-pass. Calibration error (ECE) drops from 0.82 to 0.30 on scans.

How accurate is this Nepali OCR?

Numbers below come from hash-frozen evaluation sets with bootstrap 95% confidence intervals. Nothing here is a vendor claim; every row can be reproduced from the repository.

Set CER (95% CI) Exact-token recall
Modern government PDFs (n=41) 0.135 [0.097–0.186] 0.877
Letterpress books, 20th century (n=69) 0.434 [0.387–0.481] 0.647

CER (character error rate) is the edit distance to ground truth over the number of ground-truth characters — 0 is perfect, lower is better. On the hard, table-heavy slice of the government PDFs, VeriScript scores below raw engines and the CPU-friendly middle of the field while staying offline (full head-to-head in the benchmark). Speed: roughly one second per clean page, two to four seconds on letterpress material, on CPU.

What it is honest about

  • Handwriting is out of scope — printed text only.
  • Heavy phone photos degrade recognition (measured CER 0.757 on the heavy synthetic proxy; recognition, not the review layer, is what breaks).
  • More than two columns is unsupported; complex forms are weaker than prose and tables.

What do people use it for?

  • Digitising citizenship papers, certificates and land deeds — locally, without uploading family documents.
  • Making scanned Nepali and Hindi PDFs searchable for archives, libraries and law offices.
  • Turning letterpress books and newspapers into text and Markdown for research and publishing.
  • Reading invoices and ledgers where a wrong digit matters more than a pretty layout.

Does my document leave my machine?

With a local install, no: the pipeline is designed to run with networking disabled, and there are no cloud calls, no account and no telemetry. The studio at veriscript.live is a demo — the page is processed on the server and deleted after the 60-minute retention window, and page content is never logged.

Install from the GitHub repository (pip install -r requirements.txt, MIT), or point the demo at one page first.

Questions

Is there a free Nepali OCR that works offline?

Yes. VeriScript is open source (MIT) and runs on your machine — no cloud calls, no telemetry, no account. The hosted studio is only a demo and deletes uploads after 60 minutes.

How accurate is VeriScript’s Nepali OCR?

On frozen sets: modern government PDFs score CER 0.135 [0.097–0.186]; letterpress books 0.434 [0.387–0.481]. The review queue surfaces 88% of wrong digits (letterpress) and 38% (PDFs) within its first ten rows. Full tables and reproduction commands are in the public benchmark.

Does it read Nepali handwriting?

No. VeriScript is for printed text — letterpress, government PDFs, newspapers, invoices. Handwriting is a weak point and better served by other tools; saying so is part of the honesty the project is built on.

Does my document leave my machine?

With a local install, no — the pipeline runs with networking disabled. The demo studio processes the page on the server and deletes it after the 60-minute retention window. Nothing about page content is logged.

Can I use it commercially?

The VeriScript code is MIT and the OCR stack is Apache-2.0. The optional photo-upscaler weights are non-commercial and are excluded from commercial builds; the document studio does not include them.

Does it output a searchable PDF?

Yes — a cleaned page with an invisible Unicode text layer (Devanagari included, bundled Mukta font) alongside the restored image, a numbered review overlay, plain text, Markdown and OCR JSON.
